# Codex Mod (Minecraft 1.20.1)

This is a starter **Fabric** mod for **Minecraft 1.20.1**.

## What it adds
- `codexmod:ruby` item (appears in the Ingredients tab)

## Requirements
- Java 17
- Gradle (or use the included wrapper if you add it)

## Build
```bash
./gradlew build
```

The built jar will be in `build/libs/`.

## Run in dev
```bash
./gradlew runClient
```

## Notes
- The item texture file `src/main/resources/assets/codexmod/textures/item/ruby.png` is currently a placeholder path and should be added before release.
