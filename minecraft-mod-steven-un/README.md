# Steven UN (Forge 1.20.1)

A starter Minecraft Forge mod for **Minecraft 1.20.1** themed around Steven Universe vibes.

## Features
- Adds **Cookie Cat** (`stevenun:cookie_cat`) as a food item.

## Setup
1. Install JDK 17.
2. In this folder, run:
   - `./gradlew genIntellijRuns` (or `genEclipseRuns`)
   - `./gradlew runClient`

## Build
- `./gradlew build`
- Output jar: `build/libs/stevenun-1.0.0.jar`

## Notes
- Texture file is currently a placeholder path (`assets/stevenun/textures/item/cookie_cat.png`). Add your own PNG for proper in-game icon.
