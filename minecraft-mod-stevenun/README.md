# Steven Un Mod (Forge 1.20.1)

A starter Minecraft Forge mod for **Minecraft 1.20.1**.

## What it adds
- A new item: `steven_ingot`
- The item appears in the **Ingredients** creative tab.

## Build and run
From this folder:

```bash
./gradlew genIntellijRuns
./gradlew runClient
```

To build a jar:

```bash
./gradlew build
```

Output jar:

`build/libs/stevenunmod-1.0.0.jar`
