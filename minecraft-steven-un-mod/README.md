# Steven Un Mod (Forge 1.20.1)

A minimal Minecraft Forge mod template for Minecraft **1.20.1**.

## Requirements

- Java 17
- Gradle (or use a Gradle wrapper you generate locally)

## Run in development

```bash
./gradlew runClient
```

## Build jar

```bash
./gradlew build
```

The built jar will be in `build/libs/`.
